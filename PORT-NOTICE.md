# Unofficial backport notice

This project adapts Okaeri Game Studio's MobsBeGone from Minecraft 1.21.1 Fabric to Minecraft 1.20.1 Fabric.

- Original source: https://github.com/OkaeriGameStudio/MobsBeGone
- Original authors: Olivia and EasyMochi
- Upstream license: MIT; see `LICENSE` for the complete notice.
- Changes for this backport: Minecraft/Fabric dependency versions, Java target, 1.20.1-compatible default entity list, identifier lookup for the older game API, and bounds-safe blacklist lookup. The upstream configuration path, JSON format, and spawn-blocking behavior are retained.
- No upstream CurseForge or Modrinth listing artwork was copied into this source tree.

This unofficial port is maintained separately and is not endorsed by Okaeri Game Studio or the original authors.
